## Two things to say before a reviewer asks

**The reports 02–05 still read "These four numbers" above a table of five.** The sentence predates the two-score split (D-32) and was corrected in `code/18_generate_report.js` on 5 August — *after* these reports were generated. They are deliberately **not** edited: they are the output of runs that actually happened, and rewriting them afterwards would make them worse evidence, not better. Reports generated from now on carry the corrected wording. See `decision_log.md` D-39.

**Report 05 shows `screening_score: 100` on a page where nothing was examined.** No HTML checks ran (pasted text) and the AI failed, so zero checks found zero problems. The same report says "not computable" for all three instrument subscores and states that all checks were skipped — but that one row is inconsistent with the rest of its own document. Known defect, documented in `decision_log.md` D-36, deliberately not fixed before submission. It did not affect safety: that audit still routed to a human, because R2 and R7 fired.
