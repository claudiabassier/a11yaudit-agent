## 3. Pre-commit checks — run these, don't assume

```bash
cd <repo-root>

# 1. Nothing secret is about to be committed
grep -rn "sk-ant-api" --include=* . | grep -v ".env"     # expect: no output
grep -rn "N8N_ENCRYPTION_KEY=" --include=* . | grep -v ".env"
#    expect only: docker-compose.yml (a ${VARIABLE} reference)
#                 .env.example       (the literal word "changeme")
#                 build_runbook.md   (the literal "<from .env>")

# 2. .env is actually ignored
git check-ignore -v .env                                  # expect: a match

# 3. What git will actually stage
git status --short
```

**Look at every screenshot before committing.** Text greps cannot read images, and an API key in a PNG is the failure mode this project already had once.

## 4. Creating the repository

```bash
cd <repo-root>

git init
git add .
git status --short          # READ THIS — confirm .env is absent
git commit -m "A11yAudit — AI-assisted accessibility and health-literacy screening for digital health content

Turing College AI Capstone (Case 3). Self-hosted n8n + Postgres 16.
Deterministic HTML checks and a safety prescreen, one validated AI call
grounded in WCAG 2.2, PEMAT-P and the CDC Clear Communication Index, and a
deterministic decision engine that routes safety-relevant content to a human
reviewer regardless of what the AI returns.

Design principle: the AI proposes, deterministic rules dispose."
```

Then on github.com create a **new empty repository** — no README, no .gitignore, no licence, since all three already exist here — and:

```bash
git remote add origin https://github.com/<your-username>/a11yaudit.git
git branch -M main
git push -u origin main
```
